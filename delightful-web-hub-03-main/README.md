# 🎉 CampusFest 2026

> **Celebrate. Compete. Create.**

CampusFest 2026 is a modern and responsive **College Event Website** designed to showcase college events, schedules, activities, registration details and event highlights.

This project was created as a **college web development and cloud deployment demonstration project**.

## 📌 About the Project

CampusFest 2026 provides students with a simple and attractive platform to explore upcoming college events and festival activities.

The website includes information about:

* 🎭 Cultural Events
* 💻 Technical Events
* 🤖 Robotics
* 🚀 Hackathons
* 🎸 Music & Entertainment
* 📸 Photography
* 📅 Event Schedule
* 📝 Event Registration
* 🖼️ Event Gallery
* 📞 Contact Information
